VANSHIKA MAKHEJA — TEXTILE DESIGN CV

HOW TO OPEN
1. Right-click this ZIP and choose “Extract All”.
2. Open the extracted folder.
3. Double-click index.html.
4. If asked, choose Google Chrome or another modern browser.

Keep all three files in the same folder; the page works offline.
Click a cart item to open its individual CV receipt. Use “Print / Save as PDF”
inside a receipt to print that selected section.

EDITING
- Update page text, trolley cards, and receipt content in
  index.html.
- Change colours, layout, and responsive styling in styles.css.
- Change filters, receipt interactions, and contact actions in script.js.

Note: This is a portfolio website, not a deployed public web URL.
